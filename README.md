# My Study Planner

Website jadwal belajar pribadi menggunakan HTML, CSS, dan JavaScript.

## Menjalankan di VS Code
1. Ekstrak folder `my-study-planner`.
2. Buka VS Code.
3. Pilih **File > Open Folder** lalu pilih folder proyek.
4. Buka `index.html` di browser. Disarankan memasang ekstensi **Live Server** di VS Code, lalu klik kanan `index.html` > **Open with Live Server**.

## Mengunggah ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `my-study-planner`.
2. Unggah `index.html`, `style.css`, dan `script.js` ke repository (jangan hanya mengunggah folder ZIP).
3. Buka **Settings > Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses selesai. Website akan tersedia di `https://USERNAME.github.io/my-study-planner/`.

## Catatan notifikasi
- Klik tombol **Aktifkan notifikasi** dan izinkan notifikasi browser.
- Pengingat diperiksa setiap 30 detik pada Selasa–Jumat pukul 19.30 waktu lokal perangkat.
- Halaman website harus tetap terbuka agar pengingat ini berjalan. GitHub Pages sendiri tidak menjalankan JavaScript ketika halaman ditutup.
- Checklist disimpan di localStorage browser/perangkat yang digunakan. Data tidak otomatis tersinkron ke perangkat lain.
